# 9:16 视觉与动效规范

读取时机：方案、关键帧、布局/动效修订。V01–V23、M01–M13。

## 布局不是一张模板

- **V01 画布**：默认 1080×1920、30 fps；输入另有约束先确认。所有坐标按画布缩放，不把横屏构图缩小后塞进竖屏。
- **V02 两种核心模式**：`presenter` 真人主轨负责信任/金句/简单解释，贴图落在脸下或留白；`evidence-pip` 真实资料/复杂流程成为主画面，右下圆形人物负责讲解。少量纯图解模式需说明，不默认长期取代真人。
- **V03 按时长约 2:1**：统计模式区间并说明过渡归属。长答案连续播放比机械达成精确比例重要；本片约 1.68:1 的后期修订也被保留。这个容许值是案例，不是所有片的硬标准。
- **V04 解释少留真人**：一句金句、一个词、短提醒在主画面加重点即可；内容很多、关系复杂或要读真实截图才退圆窗。不因已有流程组件就把全片做成 PPT。
- **V05 圆窗置顶**：图片/视频/流程/描边在后，圆窗在上；字幕和常驻标题分独立区域，不能相互覆盖。圆窗边框始终圆形，裁切缩放时也不变方框。人物同帧、静音，不增加第二条口播。
- **V06 互不挡重点**：圆窗不可被遮，也不可挡正在读的截图文字；必要时移动截图的聚焦区或圆窗，不把“人物最高层”误解为“可以压证据”。

## 手机 UI 安全与人脸保护

- **V07 实际安全区**：抖音/小红书平台 UI、设备和展开介绍会变化；不能声称有跨平台唯一官方安全数值。新项目核对目标平台当前截图/官方模板，先按保守边界排，再手机预览。
- **V08 本片验证尺度**：1080×1920 中常用主信息 x≈60–970，顶部主题 y≈130；字幕 top=1400、font=47、常用高度约 86px；圆窗 x≈700、y≈1100、直径270。它们是 V5.6 继承的案例坐标，不是官方标准或适用于所有身高/镜位的固定值。
- **V09 预留平台区域**：底部约 20%–22%、右侧约 10%、顶部约 6%–8%先不放关键内容，最终以当前 UI 校验。字幕接近 y=1400（画布约73%）而非贴到底；主体与字幕之间留间隙。来源小字仍不能放到会被遮的地方。
- **V10 动态护脸**：看源片代表帧和人物移动范围，不只看首帧。所有人物主画面注解避开眼鼻嘴、下巴；开场主题“视觉居中”也必须让位于脸，可下移到下巴以下，不为绝对几何中心挡脸。
- **V11 不必要滤镜禁止**：保持人物原色。可局部中性黑透明底增强可读性，或在经过关键帧审核的短主题镜头使用轻压暗蒙版；不得全屏套紫色或擅自美颜/调肤色。
- **V12 可调透明度**：小图/说明可半透明使人物透出，但真实证据仍须可读。大而密的图切为主画面＋圆窗，不用低透明度硬盖人脸。

## 字体与层级（手机上看，而非只看电脑）

- **V13 尺度参考**：主题74px、常驻标题40px、关键数字104px、主要短词/步骤48–64px（较长词可43–48px）、图标64–84px、字幕47px、次要来源31–38px。本片实际用了 PingFang SC/Arial 等可用字体；可换已授权中文字体，但先验收字形、字重、乱码和宽度。
- **V14 360px 预览**：单帧原尺寸＋手机宽总览都要检查。短词如“寿命、金钱、自由”必须大而醒目，前配语义图标；看不清时优先减少文字、扩大相关图区域，不只是继续缩小字。
- **V15 色彩**：白色承载正文，粉/青作为强调，蓝紫用于部分图解背景或线条。对比清晰、轻阴影/细描边即可，普通字幕不跟每个词换色。
- **V16 框的边界**：短词、步骤标题不用大外框。开场主题的黑透明阅读层、真实 UI 的原框、截图聚焦描边和必要证据容器允许；不能误读为“所有画面永远不能有任何框”。

## 开头与信息持续性

- **V17 主题优先**：首先突出当前视频真实主题，不把《高性价比人生指南》偷换为“650 人生建议”。大主题、短价值副标题、少量工具/数量信息构成层级，口播没说到的具体内容不得抢先全亮。新视频使用它自己的主题/数字/案例，不能硬编码本案例的指南、650、Codex或搬家。
- **V18 开场状态链**：大主题在安全中央/下巴以下的黑透明阅读层入场→轻放大并停留→平滑收成顶部一行标题＋下划线，之后常驻；不是标题一闪就消失。当前案例上移约6.8–7.5秒，新片取同源口播锚点，不能照抄秒数。
- **V19 数字滚动**：V4/V5.2 的650滚动保留，可迁移到别的可信数字。听到对应数字才启动/落定，最后数字稳定可读，不无端更换真实截图上的657/667等版本数据。
- **V20 结果预览**：讲“做成工作台/系统”应在此处短暂展示真实入口或结果，让观众有成果感。不是只加 Codex 图标就当展示了工作台。
- **V21 固定识别**：顶部主题/下划线、适当章节或进度提示维持上下文。进度条在安全上方或下方，章节高亮依据实际话题区间；长标题/进度条竞争时减层，不堆成拥挤页眉。
- **V22 图标不是空装饰**：收藏粉色小标后必须有“先收藏/第一反应”内容；工具图标与资料调用的关系明确。示意工具标不能冒充官方商标。
- **V23 收束**：复杂图解结束回到真人，给清晰下一步。CTA 不盖脸，不凭模板额外编造用户未说的产品承诺/引导。
- **V24 章节进度条**：章节由真实 SRT 与分镜语义合并得到，数量按内容决定；每段只有一个状态，已完成低亮、当前强调并按实际播放时间填充、未开始灰显。它只做导航，不代替标题，不使用彩虹色或装饰图标；默认关闭固定视频标题，进度条置于平台安全区并避开脸与主要证据。

## 动作的规则

- **M01 有效变化**：每3–5秒至少规划一个新信息/阅读焦点/关系变化：图标逐项、数字、截图定位、关键词、连线、局部放大、主图↔真人。只有颜色变、轻微呼吸、同一页面停很久不算。
- **M02 口播约束更高**：3–5秒不是每3秒硬切，也不是文字定时自动轮播。实际话语没有新内容时可停留阅读，记录理由，不能提前露出后两步。
- **M03 一镜三段**：入场→可读停留→出场，不能新素材突然出现、旧素材突然删除。进场和出场方向有逻辑关系，避免每镜同一呼/同一翻页。
- **M04 克制动作库**：轻推入/升起、短弹性落位、遮罩展开/翻页、透视折转、划线描画、路径描线、计数滚动、聚焦放大、退回真人。大幅动作集中在主题/转折，禁止无意义粒子/不停转动截图。
- **M05 动画不抢词**：节点到触发词才出现；可读性迅速建立。上游动画长到词说完还没见文字时缩短动画，不提前渲染关键词“补偿”。
- **M06 阶段递进**：先步骤主题→编号/图标和当前一步→箭头→下一步；已说步骤保留降亮，当前步骤突出，最终形成完整结构，不开头一次性展示全部答案。
- **M07 目录例外**：若口播明确先给目录，可总览；后续细节仍按序展开。不能拿对标六工具总览去推翻本片三步不能提前剧透的要求。
- **M08 四象限**：四类资源在真人脸下坐标/2×2组织，图标＋大词随话出现；“时间与精力”按原话是一类，不拆成五张字卡，不切掉人物逐张全屏字。
- **M09 反差保留上下文**：三个选择图标随各词出现并保留；说“只能凭感觉”时原图降至约25%，新大字/轻扩散圈浮在上，不清空成一行孤字。
- **M10 否定与替代**：“不是讲道理”可局部划掉，再重点强调“成本→收益/算清账”；“收藏→调用”可用粉标和明确替代文字，不把错误音效或巨大红叉当必需。
- **M11 丝滑读证据**：项目截图→收回短暂真人→工作台截图，运动方向一致；问题全景→放大输入→继续答案→聚焦结论→收回人物，保持观众空间认知。
- **M12 按帧可复现**：所有状态由 frame/fps/start/duration 计算。Remotion 中用帧驱动；HyperFrames 使用其可 seek 合同。禁用 setTimeout、播放历史相关 CSS 动画、无种子随机数让截图与成片不一致。
- **M13 检查中间帧**：稳定关键帧通过不代表转场通过；对进入、过渡中点、退出抽连帧并播放，检查圆框突然变方、人像双重曝光、闪黑、位置突跳和遮脸。
