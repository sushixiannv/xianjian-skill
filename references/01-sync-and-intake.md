# 素材盘点与唯一时序基线

读取时机：新任务盘点、转录、同步问题或源片/SRT 变更。规则 T01–T17。

## 先确认输入状态

- **T01 干净初剪**：用户已剪掉口误、气口就不再运行粗剪。优先源片而不是带旧贴图的成片；不可用删除旧图层的承诺替代实际干净来源。
- **T02 素材对应**：记录文件、角色、时长、尺寸、帧率、音频采样率、是否变帧率、是否烧字幕、SHA256。附件排序与文件身份冲突时以实际内容核对，不凭“第几个附件”猜。
- **T03 目录先审批**：已有项目复用根目录；首次创建先给位置/结构方案，用户确认再建。建议媒体目录 `日期_标题`，日期不确定用“制作日期”，不要虚构发布时间。
- **T04 视频分析证据**：ffprobe 确认是视频，按真实秒数 seek 抽帧、看接触表，再对相关转场密集抽帧并核对音频。说明抽样范围，不声称看过全部帧；静图不能证明声音、转场或滚动效果。
- **T05 参考范围**：用户排除的部分不分析；只学习剪辑规律，不把他人的商业结果复制为用户事实，也不将对标视频整段当成己方素材。

## 本地 SRT 生成与纠错

- **T06 默认本地**：优先已安装的中文多语 Whisper / whisper.cpp；检查可执行文件和模型，不能给中文用 `small.en`。先提取当前源片的音频，保留完整时间与采样信息。未授权不送云端/付费 ASR。
- **T07 复用验收稿**：已有本地验收 SRT 时核对对应源片和哈希，直接复用；剪映稿只能作为另一个候选比较，不擅自换时序真源。本片唯一基线是已批准本地 Whisper 稿。
- **T08 三状态**：原始转录 `raw.srt` 留底；文字纠错形成 `corrected.srt` 与纠错表；同步审核后 `approved.srt` 冻结。不要覆盖 raw，也不要把原始识别拼写当成最终字幕文本。
- **T09 专名校正**：Codex、GitHub、Remotion、HyperFrames、Obsidian、产品名/项目名按真实口播与素材核对；识别提示是词典，不是往口播里插入不存在的内容。保留即兴表达，不改写成书面稿。
- **T10 文字≠时间**：只改错字/标点不改 start/end；若时间错了，先做变更比较并重新验收。获批后生成新锁，所有受影响锚点、帧、音效一起更新，不混用两版。

## 句级和词级分别负责什么

- **T11 字幕**：每一条 cue 的整行文字从批准 start 到 end 完整显示，不做逐字动画。断行/拆条不得凭字数分摊时间；过长时回听句内停顿取得新边界，获批再冻结。暂时两行要明确审核，不缩成小字。
- **T12 配图**：句内关键词用同源词级 JSON 或人工回听锚点；文件保存 cueId、实际词、audioTime、核对方式/证据。SRT 只有一句的起止时，不能证明每个词开始时间，不能插值“精准同步”。
- **T13 三类时间**：主片绝对时间、短样片局部时间、辅助录屏源时间分开记。例如样片从 60 秒开始，局部 5 秒对应主片 65 秒；录屏又有独立 sourceIn。不得直接搬 V4 短片的 3 秒到主片 3 秒。
- **T14 帧量化**：图形首次出现帧 `ceil(audioTime × fps)`，不提前揭示未来词；误差上限小于一帧。音效以该视觉落点为起点，剔除素材前导静音。进场可以移动空白表面，但不能预先显示未来关键词。
- **T15 唯一声音时钟**：主口播始终连续；辅助录屏允许静音减速/暂停/聚焦以适配讲解，但不得反过来拉伸主片、SRT 或口播。
- **T16 同步测试**：首次转录或来源不明时，抽听首尾、每个步骤、数字、示例问题、答案和回场；制作有声短测试。已验收不重做，除非文件或时间变了。哈希一致只能证明文件没变，不能证明 ASR 本来就准。
- **T17 风险前置扫描**：进入视觉设计前先标记专名/数字、演示案例、隐私、真实截图/答案缺口、授权与平台安全区风险；高风险句先建立证据配对或降级方案，不能等全片渲染后才发现没有可用素材。

## 门禁与产物

Gate A0：输入清单与目录确认。Gate A1：口播/字幕同步基线确认。

`timeline-lock.json` 保存源片/SRT 哈希、媒体时长、fps、每条 cue 的起止和文字。`word-anchors.json` 属于该锁；锚点 ID 由 `storyboard.json` 和音效表共用。缺少锚点只阻塞对应句内精确动效，不必阻塞已核对的所有部分。

工具调用不是记忆中的固定绝对路径：发现 `media-transcript-extractor` 时读其当前说明并复用本地脚本。它的“标准 Markdown 稿”是素材分析入口，但本流程**渲染的时序入口仍是 approved.srt＋同源词锚点**，不要混淆两个用途。

## 使用校验脚本

```bash
node SKILL_DIR/scripts/timeline-contract.mjs lock --video SOURCE.mp4 --srt approved.srt --fps 30 --out timeline-lock.json
node SKILL_DIR/scripts/timeline-contract.mjs validate --lock timeline-lock.json --video SOURCE.mp4 --srt approved.srt --plan storyboard.json
node SKILL_DIR/scripts/timeline-contract.mjs compare --before approved.srt --after candidate.srt
```

脚本帮助查哈希、cue/词锚点引用、边界、图形提前、帧偏移和图解占比；不能替代听原音，也不能判断素材事实真假或设计是否好看。事件和模式的数据合同见 [09-timeline-contract.md](09-timeline-contract.md)。
