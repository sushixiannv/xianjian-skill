## 不应该再次启用的旧做法

| 旧想法/失败尝试 | 本版裁决 |
|---|---|
| 字幕逐字跟口播打字 | 不采用；只有重点配图逐项触发 |
| “整页不能出现”或“完整页就一直读” | 都不绝对化；完整概览用于定位，真正阅读靠相关局部放大 |
| 全片都右下小圆窗 | 不采用；按信息复杂度切模式，约2:1 |
| 四词切成四张全屏字 | 不采用；图标＋坐标分类，保留真人 |
| 一开始三步全部显示 | 不采用；目录总览仅在口播有总览意图时允许 |
| V3前10秒完全像素原样复制 | 后续开场确认已覆盖；保留其信息密度/主题持续性，采用下移大主题→上方下划线 |
| 配色换了就算3–5秒变化 | 不采用；必须新的焦点/关系/素材状态 |
| 只给文字，漏掉工作台与真实答案 | 不采用；must-have逐项覆盖 |
| 声音每字幕都敲键盘 | 不作为规则；声音由实际动作选择，允许留白 |
| 全片BGM更大/音乐+音效 | 不采用；最终选择无BGM |
| 金币/错误/疑问等V5.7换音色 | 不采用；用户明确否决，不把提议当成功 |
| V5.8新开场更重 | 不纳入；用户选截至V5.6作为本Skill基线 |
| 必须安装/运行每个工具才算流程完整 | 不采用；能力按需调用，交付实效可检验 |
| 原生剪映工程已经可导出 | 尚未验证，不承诺 |
| 我们已超越对标/已是商业成品 | 尚未验证，不宣传 |

这些规则的证据是用户在同一条视频多轮反馈与最终选V5.6，并不证明已在所有题材/平台/镜位复现。下批新片验证后再升级默认参数。
